SimActive boosts script processing speed in Correlator3D

By jnally on 8 September, 2026
FacebookXShare

SimActive has announced a new interactive mode in Correlator3D, designed to accelerate automated workflows.

Users can now run multiple Correlator3D scripts in succession within the same session, avoiding delays between operations and reducing total execution time.

SimActive says the feature should be especially useful for repetitive workflows involving several short scripts:

  • The software remains ready for the next operation after each script is finished, making the overall process faster and more efficient.
  • Completion messages can be generated to aid integration with external automation tools.

SimActive describes Correlator3D as an end-to-end photogrammetry solution for the generation of high-quality geospatial data from satellite and aerial imagery, including drones.

The software performs aerial triangulation and produces dense digital surface models, digital terrain models, point clouds, orthomosaics, 3D models and vectorised 3D features.

“Automation plays an important role in large-scale mapping workflows,” said Louis Simard, CTO at SimActive.

“This new mode helps users complete automated workflows faster, particularly when numerous short operations must be performed.”
